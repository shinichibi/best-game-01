**PRISM BREAK v2** is a neon twin-stick arena survival shooter that runs entirely in the browser. You pilot a lone prism ship against escalating waves of living glass: shardling chasers that hunt you down, needle darts that telegraph and lunge, slalom weavers, mitosis splitters that divide when broken, bulwark tanks that burst into darts, and wisp orbiters that circle and shoot back — and every fifth wave the Grand Prism itself descends, a rotating three-shelled boss with radial bullet rings, aimed fans, spirals and minion calls. Chain kills inside the combo window to climb to a x9 multiplier, dash through danger with a burst of invincibility, and grab the weapons the wreckage drops: the five-pellet Helix Scatter, the piercing Lance Rail, the homing Swarm Seekers and the rapid Nova Pulse, each on a timer before your Prism Blaster returns. Particle explosions, shockwaves, dash ghosts, screen shake, slow-motion hits and a parallax starfield over a scrolling perspective grid keep every second loud, and every sound — shots, explosions, pickups, the boss alarm — is synthesised live with Web Audio. No assets, no network: just code.

## Run it

```sh
python3 -m http.server 8080 -d game
```

Then open http://localhost:8080 in desktop Chrome and click to start. (To build the make.fun hand-in instead, run `MAKEFUN_OUTPUT_DIR=out node main.ts`.)
